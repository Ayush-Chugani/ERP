This document converts the supplied SQL structure into a controlled implementation sequence. Run the prompts in order and carry forward the approved decisions and generated repository state. Each prompt requests production code, tests, commands, and verifiable acceptance criteria.

How to use this prompt pack
Start a dedicated ChatGPT project or coding conversation with access to the repository. Paste the Project Context Prompt once, then execute Prompts 1 through 19 in order.
Before each prompt, commit or otherwise checkpoint the working code. Give ChatGPT the current repository tree, relevant existing conventions, and the output of the previous prompt.
Review schema and authorization decisions before accepting code. Do not run generated migrations against production until they have been inspected and tested against a backup or staging copy.
Require every prompt to finish its tests and acceptance checklist. Resolve blockers before moving to the next prompt.

Appendix A  Supplied baseline SQL

CREATE TABLE university (  university_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  university_code VARCHAR(30) NOT NULL UNIQUE,  university_name VARCHAR(200) NOT NULL,  legal_name VARCHAR(250) NULL,  university_type ENUM('CENTRAL','STATE','PRIVATE','DEEMED','OTHER') NOT NULL DEFAULT 'OTHER',  website_url VARCHAR(255) NULL, email VARCHAR(254) NULL, phone VARCHAR(25) NULL,  address_line_1 VARCHAR(200) NULL, address_line_2 VARCHAR(200) NULL,  city VARCHAR(100) NULL, state_id SMALLINT UNSIGNED NULL, postal_code VARCHAR(12) NULL,  is_active BOOLEAN NOT NULL DEFAULT TRUE,  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,  CONSTRAINT fk_university_state FOREIGN KEY (state_id) REFERENCES state(state_id));
CREATE TABLE institution (  institution_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  university_id SMALLINT UNSIGNED NOT NULL,  institution_code VARCHAR(20) NOT NULL UNIQUE,  institution_name VARCHAR(200) NOT NULL, legal_name VARCHAR(250) NULL,  website_url VARCHAR(255) NULL, email VARCHAR(254) NULL, phone VARCHAR(25) NULL,  is_active BOOLEAN NOT NULL DEFAULT TRUE,  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,  CONSTRAINT fk_institution_university FOREIGN KEY (university_id) REFERENCES university(university_id));
CREATE TABLE campus (  campus_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  institution_id SMALLINT UNSIGNED NOT NULL, campus_code VARCHAR(20) NOT NULL,  campus_name VARCHAR(150) NOT NULL, address_line_1 VARCHAR(200) NULL,  address_line_2 VARCHAR(200) NULL, city VARCHAR(100) NULL,  state_id SMALLINT UNSIGNED NULL, postal_code VARCHAR(12) NULL,  phone VARCHAR(25) NULL, email VARCHAR(254) NULL, is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT uq_campus_code UNIQUE (institution_id, campus_code),  CONSTRAINT fk_campus_institution FOREIGN KEY (institution_id) REFERENCES institution(institution_id),  CONSTRAINT fk_campus_state FOREIGN KEY (state_id) REFERENCES state(state_id));
CREATE TABLE department (  department_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  campus_id SMALLINT UNSIGNED NOT NULL, department_code VARCHAR(20) NOT NULL,  department_name VARCHAR(150) NOT NULL, department_type VARCHAR(30) NULL,  is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT uq_department_code UNIQUE (campus_id, department_code),  CONSTRAINT uq_department_id_campus UNIQUE (department_id, campus_id),  CONSTRAINT fk_department_campus FOREIGN KEY (campus_id) REFERENCES campus(campus_id));
CREATE TABLE programme (  programme_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  department_id SMALLINT UNSIGNED NOT NULL, programme_code VARCHAR(30) NOT NULL UNIQUE,  programme_name VARCHAR(150) NOT NULL, award_name VARCHAR(150) NULL,  programme_level ENUM('UG','PG','DIPLOMA','CERTIFICATE','DOCTORAL','OTHER') NOT NULL,  duration_semesters TINYINT UNSIGNED NOT NULL, maximum_duration_semesters TINYINT UNSIGNED NULL,  is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT chk_programme_duration CHECK (duration_semesters > 0 AND    (maximum_duration_semesters IS NULL OR maximum_duration_semesters >= duration_semesters)),  CONSTRAINT fk_programme_department FOREIGN KEY (department_id) REFERENCES department(department_id));
CREATE TABLE programme_specialization (  specialization_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  programme_id SMALLINT UNSIGNED NOT NULL, specialization_code VARCHAR(30) NOT NULL,  specialization_name VARCHAR(150) NOT NULL, is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT uq_specialization_code UNIQUE (programme_id, specialization_code),  CONSTRAINT uq_specialization_programme UNIQUE (specialization_id, programme_id),  CONSTRAINT fk_specialization_programme FOREIGN KEY (programme_id) REFERENCES programme(programme_id));
CREATE TABLE building (  building_id SMALLINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  campus_id SMALLINT UNSIGNED NOT NULL, building_code VARCHAR(20) NOT NULL,  building_name VARCHAR(100) NOT NULL, is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT uq_building_code UNIQUE (campus_id, building_code),  CONSTRAINT fk_building_campus FOREIGN KEY (campus_id) REFERENCES campus(campus_id));
CREATE TABLE room (  room_id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,  building_id SMALLINT UNSIGNED NOT NULL, room_code VARCHAR(20) NOT NULL,  room_name VARCHAR(100) NULL,  room_type ENUM('CLASSROOM','LAB','SEMINAR_HALL','AUDITORIUM','OFFICE','OTHER') NOT NULL,  capacity SMALLINT UNSIGNED NULL, is_active BOOLEAN NOT NULL DEFAULT TRUE,  CONSTRAINT uq_room_code UNIQUE (building_id, room_code),  CONSTRAINT fk_room_building FOREIGN KEY (building_id) REFERENCES building(building_id));
Appendix B  Module acceptance criteria
All eight entities are represented with verified MySQL constraints and reversible Django migrations.
All reads and writes are restricted by institution, campus, department, module activation, role, and record scope.
Cross-hierarchy references and unsafe structural moves are rejected transactionally.
APIs are versioned, paginated, filterable, documented, and protected by JWT authentication.
React screens support accessible list, detail, create, edit, deactivate, reactivate, and hierarchy navigation workflows.
The PWA is installable and provides safe offline read access without caching tokens or leaking data between users.
Backend tests run against MySQL; frontend tests cover permissions, validation, API failures, and offline states.
Gunicorn and Nginx deployment configuration, migration procedure, backups, monitoring, and rollback are documented.
