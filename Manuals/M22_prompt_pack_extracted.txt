SIMS – MODULE 22
Conferences, Publicationsand Presentations
Enterprise Django + MySQL + DRF + React/PWA Implementation Prompt Pack
Purpose: A structured series of AI development prompts to implement the supplied database module as a production-grade SIMS component, preserving SQL semantics and integrating with the Staff Activity supertype.
1. Architecture Baseline
Backend: Python + Django + Django REST Framework (DRF).
Database: MySQL 8.x, InnoDB, utf8mb4_unicode_ci.
Frontend: React + TypeScript, mobile-first Progressive Web Application.
Authentication/authorization: integrate with the existing SIMS Django auth, roles and institutional scope.
ConferenceActivity is a specialization of StaffActivity and shares its primary key.
ConferenceEvent is reusable event/master data; many staff activities may reference one event.
ConferenceActivityIndexing is an explicit association carrying indexing status, source URL and remarks.
Referenced masters: organizer, external_organization, publisher, participation_level, event_mode, state, country, conference_contribution_type, publication_type and indexing_agency.
2. Supplied Database Contract
CREATE TABLE conference_event (
  conference_event_id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  conference_title VARCHAR(500) NOT NULL,
  conference_edition VARCHAR(100) NULL,
  organizer_id BIGINT UNSIGNED NULL,
  sponsoring_organization_id BIGINT UNSIGNED NULL,
  proceedings_publisher_id BIGINT UNSIGNED NULL,
  participation_level_id TINYINT UNSIGNED NULL,
  event_mode_id TINYINT UNSIGNED NULL,
  venue_name VARCHAR(250) NULL,
  city VARCHAR(120) NULL,
  state_id SMALLINT UNSIGNED NULL,
  country_id SMALLINT UNSIGNED NULL,
  start_date DATE NOT NULL,
  end_date DATE NOT NULL,
  conference_website VARCHAR(1000) NULL,
  brochure_url VARCHAR(1000) NULL,
  is_active BOOLEAN NOT NULL DEFAULT TRUE,
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  CONSTRAINT chk_conference_event_dates CHECK (end_date >= start_date),
  FOREIGN KEY (organizer_id) REFERENCES organizer(organizer_id),
  FOREIGN KEY (sponsoring_organization_id) REFERENCES external_organization(organization_id),
  FOREIGN KEY (proceedings_publisher_id) REFERENCES publisher(publisher_id),
  FOREIGN KEY (participation_level_id) REFERENCES participation_level(participation_level_id),
  FOREIGN KEY (event_mode_id) REFERENCES event_mode(event_mode_id),
  FOREIGN KEY (state_id) REFERENCES state(state_id),
  FOREIGN KEY (country_id) REFERENCES country(country_id)
);

CREATE TABLE conference_activity (
  staff_activity_id BIGINT UNSIGNED PRIMARY KEY,
  conference_event_id BIGINT UNSIGNED NOT NULL,
  conference_contribution_type_id TINYINT UNSIGNED NOT NULL,
  publication_type_id SMALLINT UNSIGNED NULL,
  paper_title VARCHAR(500) NULL,
  abstract_text TEXT NULL,
  proceedings_title VARCHAR(500) NULL,
  proceedings_volume VARCHAR(100) NULL,
  proceedings_issue VARCHAR(100) NULL,
  page_from VARCHAR(30) NULL,
  page_to VARCHAR(30) NULL,
  isbn VARCHAR(30) NULL,
  issn VARCHAR(20) NULL,
  doi VARCHAR(255) NULL UNIQUE,
  proceedings_url VARCHAR(1000) NULL,
  presentation_title VARCHAR(500) NULL,
  award_name VARCHAR(250) NULL,
  award_details TEXT NULL,
  award_date DATE NULL,
  FOREIGN KEY (staff_activity_id) REFERENCES staff_activity(staff_activity_id),
  FOREIGN KEY (conference_event_id) REFERENCES conference_event(conference_event_id),
  FOREIGN KEY (conference_contribution_type_id) REFERENCES conference_contribution_type(conference_contribution_type_id),
  FOREIGN KEY (publication_type_id) REFERENCES publication_type(publication_type_id)
);

CREATE TABLE conference_activity_indexing (
  staff_activity_id BIGINT UNSIGNED NOT NULL,
  indexing_agency_id SMALLINT UNSIGNED NOT NULL,
  indexing_status ENUM('CLAIMED','VERIFIED','DISCONTINUED','NOT_INDEXED') NOT NULL DEFAULT 'CLAIMED',
  source_url VARCHAR(1000) NULL,
  remarks VARCHAR(500) NULL,
  PRIMARY KEY (staff_activity_id, indexing_agency_id),
  FOREIGN KEY (staff_activity_id) REFERENCES conference_activity(staff_activity_id),
  FOREIGN KEY (indexing_agency_id) REFERENCES indexing_agency(indexing_agency_id)
);
3. Recommended Implementation Rules
Use OneToOneField(primary_key=True, db_column='staff_activity_id') from ConferenceActivity to StaffActivity.
Do not duplicate employee, institution, campus, department, academic year, generic activity title, dates, description or outcomes already owned by StaffActivity.
Use an explicit through model for conference indexing; enforce UniqueConstraint(staff_activity, indexing_agency).
Enforce conference end_date >= start_date in both Django validation and a database CheckConstraint.
Use transaction.atomic() when creating/updating the StaffActivity specialization and indexing rows.
Prefer PROTECT for historical master-data references unless the established SIMS deletion policy requires otherwise.
Normalize DOI input consistently and preserve database uniqueness. Do not infer indexing status merely from a DOI.
Use stable lookup codes for conditional business rules; never hard-code numeric master IDs.
Integrate evidence/documents with the existing SIMS document/file module when available rather than creating a second storage subsystem.
Apply institution/campus/department and employee ownership scope in every queryset and write operation.
