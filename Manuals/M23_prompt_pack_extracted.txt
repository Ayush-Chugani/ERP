Enterprise Django + MySQL + DRF + React/PWA Implementation Prompt Pack
This document contains a sequenced set of AI development prompts for implementing the professional_development_activity module in an enterprise-grade SIMS. Execute the prompts in order and adapt names only to the existing repository conventions.
1. Module Architecture
professional_development_activity is a subtype of staff_activity; staff_activity_id is both its primary key and foreign key.
Program categories are driven by training_program_type and can represent Workshop, FDP, STTP, Training, Certification, and other configured types.
Referenced masters: organizer, external_organization, funding_agency, state, country, event_mode, plus the existing staff/institution hierarchy.
Target architecture: Django, Django REST Framework, MySQL 8+, React TypeScript, mobile-first PWA, role-based authorization, automated tests, and centralized file/document handling.
